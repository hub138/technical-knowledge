# Bundled Projects

这些目录是为了研究和本地使用而纳入本知识库的开源项目快照。每个目录保留其原始 README、许可证、测试和源码；安装依赖和启动方式以各自文档为准。

这些项目不是知识库的顶层分类，也不应替代 `vault/工程知识` 中的机制解释：

- `archify`：把架构、工作流、序列、数据流和生命周期转成可验证的交互式图。
- `OpenMAIC`：把材料和主题生成互动课堂、测验、讨论和可视化学习内容。
- `DeepTutor`：提供检索、记忆、研究、笔记和复习等学习工作区。
- `mattpocock-skills`：提供需求对齐、架构设计、TDD、代码审查等 Agent Skills。

更新上游时记录 commit、日期、许可证变化和对知识页的影响；不要把构建缓存、虚拟环境或运行时用户数据提交到主仓库。
