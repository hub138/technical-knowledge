# 图：什么时候画、怎么画才清晰

入口：要给文章/页面配架构图、流程图、时序图、数据流图、状态机时读。工具用 archify（本机与 dev 都装了，`node bin/archify.mjs`），它是 skill：读它的 SKILL.md 拿 schema 和命令，本篇只管判断与验收。

## 什么时候该画

- 讲**结构关系**（谁连谁、经过什么、边界在哪）时画；能用一句话或一张表说清的不画。
- 五选一路由：组件与边界 → `architecture`；流程与审批/调用链 → `workflow`；请求时序与返回 → `sequence`；管道与血缘 → `dataflow`；状态迁移与重试 → `lifecycle`。拿不准跑 `archify guide "<场景>" --json`。
- Mermaid 输入只取拓扑和语义，重写不照抄样式。

## 清晰的硬规则（提炼自 archify 作者约束，实测有效）

1. **一条主路径 obvious**，侧枝从最近的主路径节点分出；主节点 ≤ 12，超了先分层再画。
2. **边标签是语义数据**：协议、方向、同步/异步、跨边界机制必须保留；只有被两端点完全蕴含的措辞才可省，省了要在候选里写明理由。
3. **连线不许穿过无关节点**，不许共用模糊走廊；间距指净空，不是中心距。校验报交叉时先删低价值边或改路由，不上手动坐标。
4. **图是一等产物**：候选 → `validate`（showcase 9 项全过、0 警告）→ `deliver`（非零退出永远不许说成功）→ `visual-check`（真浏览器）→ 人眼看截图。三关独立汇报，不许拿前一关顶后一关。
5. **四档宽度无溢出**（1440/1600/1920，大图加 2048）；用 `overflow: hidden`、内滚、压字号掩盖溢出等于造假，正解是删冗余内容或压间距。
6. 默认 classic 外观、省略 subtitle；访问者语言跟随文章主语言（`meta.locale` 只管渲染器 UI）。
7. 品牌标识可选且显式：节点真名对上内置品牌才写 `brand`，不许从"数据库"这类模糊角色猜。

## 与本站的关系

- 产物是单文件 HTML（内联 SVG），可作文章附图，也可直接放页面；导出 PNG/SVG 供深色模式核对。
- 生成过程的知识（schema、命令、修复顺序）归 archify 的 SKILL.md 与它的 references，本技能不复制，只保留判断与验收标准。
