# 间距、栅格与密度

入口：动间距、边距、对齐、栅格、信息密度时读。

## 间距阶梯

`2 / 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`（TDesign M03 `--td-size-*`；区块级留白优先 16/24/32/48）。

- 相关元素之间用**小间距**（4–8），无关区块之间用**大间距**（24–48）。间距就是分组声明（Gestalt 亲密性）。
- 同一页面内不允许出现 5px、13px、18px 这种不在阶梯上的值。

## 页面骨架

- 内容区常用 12 列栅格，左右安全边距 24px（TDesign M04）。
- **三级底色必须拉开**：页面底 < 内容区底 < 卡片/侧栏/顶栏底。卡片与内容区同色 = 层级消失，只剩 border 撑边界 = 没做对。自检方法：卡片必须比内容区"浮起一档"。
- 固定侧栏 `flex: 0 0 Npx`；填充区 `flex: 1; min-width: 0`（否则内容溢出时布局炸开）。
- **侧栏放左还是放右，按内容性质判**：目录/导航类侧栏放左侧（读者从左往右扫，先见导航再读正文，docs 站惯例）；辅助信息类（同模块推荐、操作按钮、元信息）放右侧。判据只有一条：**挪动任何侧栏后，正文行宽仍须 640–760px、阅读起点不后移**；两方案都满足时再看导航效率，正文体验永远优先。用户说"更专业"不是位置依据——"专业"不是可测量的标准，位置由上面这条判据决定。

## 密度

- 技术类站点按**可读优先**，不为紧凑牺牲行高与点击区域（TDesign M04 对齐与密度）。
- 点击热区最小 44×44（移动端）；相邻可点元素之间至少 8px 间隙（ui-ux-pro-max `Touch Spacing`）。
- **删元素必须补位**：删掉一个区块后重新设计布局，不留空洞。
- **太空 = 布局错**：缩小容器、重排，不是只删元素。
- 右侧空间必须利用：目录、入口、悬浮操作、刷新按钮都有位置。留一整条空右栏是浪费。
- **同一纵向流里只允许一个宽度真源**：网格内区块（正文、收尾卡、图谱区、来源区）锚正文列宽，各定各的 max-width 时同屏出现三套宽度，左右缘互不对齐，观感「散」。**区块挪进挪出网格时宽度策略必须重推**：锚列宽的区块挪到网格外，旁边会空出右栏加列距的整块空带；随容器全宽的区块挪进网格，会铺满压到右栏下方（本项目 2026-09-24 一天之内两个方向各返工一次）。自检：网格内相邻区块宽度差 ≤ 2px（本项目 24 篇文章批量实测）；网格外区块右缘与页头右缘对齐。
- **双列布局的容器上限必须等于各列宽度加列距之和**：容器上限 1240 而两列合计 1018 时，余量 222px 全堆在两列之间，观感是正文和右栏之间一条空带（本项目宽窗口实测，用户截图圈出）。容器按内容封顶后空带在任何窗口宽度恒等于设计列距。自检：`右栏左缘 − 正文列右缘` 在 1200/1440/1920 三档视口下必须相等。
- **同屏重复出现的组块共用一套尺寸**：右栏「本文目录」与「同模块文章」标题行一 16px/粗、一 13px/灰，列表项一 13px、一 16px，同位异尺的观感是「有的太大有的太小」（2026-09-24 用户红框）。同位组块取同一套字号字重后两组实测完全一致。自检：同屏同类标题行的 computed fontSize/fontWeight 逐一相等。
- **折叠控件点击区等于标题整行**：右栏折叠行点击目标只认 36px 描边小箭头时，用户会点标题行文字却无响应（2026-09-24 用户反馈）。标题行整行接管点击（cursor:pointer，内部链接 closest('a') 放行），箭头钮 pointer-events:none 退化为纯指示器，键盘仍走钮。自检：点击标题行最左端必须触发折叠。
- **隐藏态不许占位**：淡入类元素用 `opacity:0` 隐藏但保留 `display:flex` 时，它仍占高度加 margin，在它上方压出一条固定空档（本项目奖励卡实测 66px，24 篇全中）。触发前 `display:none`、触发时才恢复布局，动画语义不受影响。
- **sticky 不许叠 sticky**：容器整体 sticky 跟随滚动后，容器内部再有 sticky 头部时，内层以容器可视顶为锚，列表从它底下滚过会被盖住（本项目目录前两行被压住，截图实测）。容器接管 sticky 后，内层 sticky 一并撤销。

## 对齐

- 子级与父级、列与列、图标与文字，逐项截图核对。
- 图标与文字在同一行时垂直居中，图标基线跟文字视觉中心对齐（不是靠 margin 凑）。
- 列表与表单主文案左对齐；一张页面上主按钮唯一。

## 响应式

- 至少在 375 / 768 / 1024 / 1440 四个宽度各看一次（ui-ux-pro-max 交付清单）。
- 移动端不允许横向滚动。
- 固定导航栏要给它预留高度，别让内容被压在下面（同库 `Content padding`）。
- **共享壳层的移动端行为用默认开（opt-out），不用默认关（opt-in）**：目录折叠、汉堡按钮这类「移动端才需要」的机制，做成挂壳层即自带；某页确实不要时显式关。做成 opt-in 的后果是每接一个新页面都要有人记得传参，漏传的页面移动端行为缺失还不报错——本项目四页侧栏永不折叠、正文起点 499px 对比首页 239px，实测 2026-09-23。
- **每类页面在移动端都要实际看一眼，桌面全绿不推及移动端**：companion 页常被当作「和首页同一套壳」跳过移动端检查；壳是同一套，页面自己的样式与初始化脚本各是各的（本项目折叠脚本只活在首页，实测漏了四页）。

## 固定框架的衔接

固定顶栏/吸底栏与内容的交界处是高频翻车点，两种形态都要防：

- **盖住**：内容被固定栏压在下面，滚动后看不到开头（上面那条）。
- **顶格**：内容紧贴固定栏下缘，边缘贴边、没有呼吸。正文或标题距固定栏下缘不得小于 16px；有全站头部规范的站点以规范值为准（本项目为 26px，真源在 `site/base.css` 的「页面头部规范」）。逐视图核对，不抽查——同一站点里头部几何各写各的，漏掉哪一个哪个就顶格（本项目实测：图谱/全景页修过贴顶栏，文章页头部独立实现，漏网）。

## 图表与画布内元素

- SVG/Canvas 内部的间距不走 DOM 阶梯，但相邻图形元素之间至少留 8px、标签与异物之间至少留 16px，判定标准与 DOM 相同：截图目测不许贴合。
- **标签冒头要算进碰撞**：画在圆/矩形边缘的标签（胶囊、名牌）会向元素外冒头，元素间距只按几何边算 1-2px 时，标签必然压到邻居身上（本项目实测：圆堆积图父圆间距 1.1px，组名胶囊直接盖住相邻圆顶）。给带外置标签的图形元素定间距时，间距 ≥ 标签冒头量 + 8px。
- 快捷键提示类**功能指示**用键帽形态（小方块 + 键位字符），不用带文字的胶囊按钮；带图标带文字的圆形悬浮钮留给**功能动作**（提意见、回顶部）。两类右下角常驻元素同形同色时，用户会把功能指示当成重复按钮（本项目实测：`?` 键帽与「提意见」FAB 同位，已改键帽形态并拉开 14px）。

自检口径并入交付清单：截图时固定栏下缘到首个大字的距离一眼可判，贴边即违规。
