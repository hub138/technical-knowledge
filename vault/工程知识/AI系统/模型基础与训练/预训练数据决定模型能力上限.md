# 预训练数据决定模型能力上限

预训练数据解决的是模型从哪里获得语言、代码、事实和推理模式。规模只是一个轴，来源质量、覆盖、去重、时效、许可证、污染和配比共同决定能力上限；最小实验是固定模型规模和步数，只替换一个数据切片或过滤规则，在未见领域和污染集上做消融。
预训练通常把“根据前文预测下一个 token”作为大规模自监督目标。这个目标能从文本、代码和多模态数据中学习统计结构，但模型质量最终受数据覆盖、质量、重复、污染、许可证和训练配方约束。扩大模型而不改善数据，常常只会更高成本地学习噪声和偏差。

## 数据管道的真实工作

```text
采集 -> 去重/去污染 -> 质量与安全过滤 -> 混合与采样
     -> token 化 -> 分片与打乱 -> 训练 -> 统计与审计
```

去重减少记忆和评测泄漏；质量过滤要保护代码、低资源语言和少数样本，不能把“容易分类”误当作“有价值”。数据混合比例改变能力取舍：代码比例影响编程，数学样本影响推理，合成数据可能放大错误模式。

## 能力、记忆与污染

损失下降是平均统计拟合的证据，不等于每个任务都变好。模型可能记住训练文本、泄露个人信息或在 benchmark 污染后得到虚高结果。评测集必须隔离、去重并记录时间；数据来源、许可证和删除请求需要能追溯到具体数据快照。

## 工程边界

- 预训练适合改变广泛能力和表示空间，不适合快速更新某条业务事实。
- 新数据可能带来遗忘、分布偏移和安全回归；继续训练不是无风险的“知识刷新”。
- 数据量、模型大小、训练 token、算力和优化器相互约束；不能只比较参数量。
- 合成数据必须保留生成模型、提示、过滤和人工抽样证据，否则质量无法归因。

## 验证

每个数据版本至少记录来源、时间、许可、语言/领域分布、去重规则、过滤率、token 数和敏感信息策略。训练或微调后按能力、事实、偏差、安全、记忆和污染分桶评测，并保留与上一个数据快照的差异。
