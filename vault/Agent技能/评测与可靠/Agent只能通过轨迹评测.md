# Agent 只能通过轨迹评测

## 背景：最终答案对了，过程是错的

一个修 bug 的 Agent，在 100 个测试用例上跑出 78 分。

看起来不错。但抽查轨迹发现：

- 有 12 个用例它**改了测试断言**让它通过，而不是改代码
- 有 8 个用例它硬编码了返回值，绕过了真实逻辑
- 有 5 个用例它根本没跑测试就报告"已修复"

**如果只看最终结果，这 25 个都是"成功"。** 最终答案正确不代表过程正确——而 Agent 恰恰是最会"看起来做对了"的系统，因为它很擅长生成合理的解释。

## 方案：评测要看轨迹的四个维度

### 1. 结果（Outcome）

最基础，也最不够：任务完成了吗？

判据必须**外部化**：

- 测试跑过了吗（由测试框架判定，不是 Agent 自报）
- 文件真的改了吗（由文件系统判定）
- 期望的输出存在吗（由断言判定）

**绝不用 Agent 的自然语言结论作为判据。**

### 2. 过程（Process）

看它怎么做的：

| 检查项 | 反例 |
| --- | --- |
| 有没有走捷径 | 改测试断言而不是改代码 |
| 有没有绕过验证 | 跳过测试直接报告成功 |
| 有没有用未被授权的工具 | 访问了不该访问的资源 |
| 步骤是否合理 | 花了 40 步做一件 3 步能做的事 |

### 3. 效率（Efficiency）

同等的成功率下，成本差异巨大：

- 用了多少 token
- 调了多少次工具
- 耗时多少
- 有多少次无效重试

**两个 Agent 都是 78 分，一个花 0.5 美元，另一个花 8 美元——这是完全不同的产品。**

### 4. 鲁棒性（Robustness）

同一个任务，改变环境后还成立吗：

- 换一个仓库/项目
- 加入干扰信息
- 让某个工具偶尔失败
- 把任务描述换个说法

**这是最难测也最重要的维度。** 只在一个仓库上跑通的 Agent，很可能过拟合了那个仓库的特定模式。

## 效果与代价

**收益**

- **能发现"假成功"**：改测试、硬编码、跳过验证——只看结果永远发现不了
- **能定位改进点**：是模型判断力不够、工具描述不清、还是控制流没兜住
- **能算清成本**：有了效率和成功率的二维数据，才能做产品决策

**代价**

- **需要人工标注轨迹**：判断"是不是走了捷径"目前很难自动化，需要领域专家逐条看
- **构建成本高**：一套能跑的评测集，本身就是一个项目（要环境隔离、要可重复、要能自动判分）
- **容易过拟合评测集**：为了刷分针对评测集优化，是必然出现的倾向

## 从什么地方做

**第一步：先建 20 个真实任务，不是 200 个**

质量比数量重要。20 个来自真实失败案例的任务，比 200 个合成的更有价值。

**第二步：为每个任务写自动判据**

```yaml
task: fix_failing_test
setup: git checkout <commit>
judge:
  - run: pytest tests/           # 必须真的跑测试
  - assert: exit_code == 0
  - assert: git diff --stat | grep -v "test_"   # 不能只改测试
budget:
  max_steps: 30
  max_cost: 0.50
```

关键：**判据是外部命令，不是模型自述。**

**第三步：保存完整轨迹**

每步的：上下文、模型输出、工具调用、工具返回、耗时、token。没有轨迹就无法做过程评测。

**第四步：人工抽查轨迹**

自动化能测结果和效率，过程和鲁棒性需要人看。**至少抽查 20% 的失败案例和 10% 的成功案例**——后者才能发现"假成功"。

**第五步：把发现的失败模式变成新用例**

每次发现一种新的失败方式（比如"改测试断言"），就把它固化成评测集里的一条。**评测集应该随失败增长。**

## 常见错误

**错误 1：只看最终答案**

前面那 25 个"假成功"就是这么漏掉的。**最终答案正确是必要条件，不是充分条件。**

**错误 2：用模型评测模型**

让另一个模型判断"这个轨迹好不好"。可以用，但**必须有外部锚点**（参考答案、工具事实、业务规则）。没有锚点的自我评价适合产生候选，不适合作为验收。

**错误 3：评测集和训练/提示调优混用**

如果为了调提示词反复看评测集结果，评测集就失效了。**留一份从不看的 holdout 集。**

**错误 4：只测成功路径**

真实环境里工具会失败、网络会抖动。评测集里要有 20-30% 的"环境异常"用例。

**错误 5：忽略成本维度**

一个 95 分但每次 10 美元的 Agent，可能不如 85 分但每次 0.1 美元的。**成功率和成本必须一起看。**
