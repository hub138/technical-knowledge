# 外部输入区

这里承接论文、开源项目、产品发布和规范变更。它不是知识主区，也不按日期建立长期分类；价值确认后，结论必须合并到 `工程知识` 中的实际主题页面。

## 快速流程

1. 新条目先放入 `知识库管理/更新候选/每日更新` 或本目录的论文/项目模板，记录来源、版本、发布日期和价值判断。
2. 每日只做去重和分流：keep、read、later、drop。
3. 每周深读 keep，提取机制、证据、边界和与现有主题的连接。
4. 通过 [[知识库管理/归档/知识演化机制.md]] 的质量门禁后，更新 Wiki 与 [[知识库管理/归档/变更记录.md]]。

论文使用 [[知识库管理/归档/来源/论文与项目/论文条目模板.md]]，项目/仓库使用 [[知识库管理/归档/来源/论文与项目/项目条目模板.md]]；每天汇总可复制 [[知识库管理/归档/更新候选/每日更新模板.md]]。长期来源和检查频率登记在 [[知识库管理/归档/来源注册表.md]]。不要把营销摘要或无来源的二手结论直接写入知识主区。
